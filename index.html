字段与交互说明

按钮交互

  • +：新增一条空的 SKU 明细行。
  • Copy：复制当前明细行数据，并追加为一条新行。
  • Remove：立即删除当前明细行；提交时仍要求至少有 1 条有效明细。
  • Submit：执行前端校验；当前版本不调用后端接口，也不做真实保存。
  • 侧边栏 Hide / Show：收起或展开左侧菜单，主内容区域同步扩展或回收。

头信息字段

字段名称 数据来源 交互方式 是否必填 备注
Creation Date 浏览器本地当前日期 只读展示 是 页面首次加载时自动填充，用户不可编辑。
Execution Date 日期选择 否 用于填写计划执行日期。
Remark 文字填写 否 用于补充说明当前调拨申请。
From Warehouse 预置仓库枚举 / 用户自定义 下拉单选 + 自定义输入 是 选择 Custom... 时显示自定义输入框；提交时取最终解析值。
To Warehouse 预置仓库枚举 / 用户自定义 下拉单选 + 自定义输入 是 选择 Custom... 时显示自定义输入框；提交时取最终解析值。

明细字段

字段名称 数据来源 交互方式 是否必填 备注
Fill In Method 录入方式枚举 单选切换 是 by quantity 按 SKU 汇总库存选择；by batch 按具体批次选择。
SKU Number SKU 本地模拟数据 点击选择 是 点击后打开 SKU 选择弹窗，并回填当前行。
SKU Name SKU 本地模拟数据 / 用户调整 文字填写 否 选中 SKU 后自动带出，也允许人工调整。
Batch Number SKU 本地模拟数据 文字填写 按模式 by batch 模式下必填；by quantity 模式下隐藏且不参与校验。
Goods Status 状态枚举 / 用户自定义 下拉单选 + 自定义输入 否 预置值包括 New、Damaged、Expired、Other...。
Quantity 数字填写 是 必须为正整数，作为当前 SKU 行的申请数量。

SKU 弹窗字段

字段名称 数据来源 交互方式 是否必填 备注
SKU Filter 文字填写 否 支持按 SKU 编号、名称、批次号、库存数量做模糊过滤。
SKU Number SKU 本地模拟数据 表格选择 是 点击 SKU 记录后回填到当前明细行。
SKU Name SKU 本地模拟数据 只读展示 否 by quantity 模式下当前弹窗主展示 SKU 编号和库存数量，名称用于过滤和回填。
Batch Number SKU 本地模拟数据 表格选择 按模式 by batch 模式下展示并回填；by quantity 模式下不回填批次。
Quantity In Stock SKU 本地模拟数据 只读展示 是 展示可用库存；by quantity 模式下按 SKU 汇总展示。

校验与反馈

  • 页面首次加载时默认生成 1 条空明细行。
  • 提交时校验来源仓、目标仓、至少 1 条有效明细，以及明细必填字段。
  • 有效明细至少需要 SKU Number 和正整数 Quantity；按批次模式还需要 Batch Number。
  • 字段错误会显示在字段附近，用户修改后对应错误会被清除。
