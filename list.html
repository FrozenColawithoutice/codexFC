PRD Guide

字段与交互说明

按钮交互

  • Search：读取当前搜索条件，并基于本地模拟数据刷新列表。
  • Reset：清空全部搜索条件，并恢复展示全部申请数据。
  • Add：跳转到 Goods Allocation Request 创建页。
  • Details：打开当前行对应的申请详情弹窗。
  • 弹窗关闭：支持点击关闭按钮、点击遮罩层或按下 Escape。

搜索字段

字段名称 数据来源 交互方式 是否必填 备注
Request Order Number 文字填写 否 按调拨申请单号做包含匹配，例如 DB202604240001。
Submitter 文字填写 否 按提交人名称做包含匹配。
Request Order Status 状态枚举 下拉单选 否 枚举包括 Approving、delivering、stock pending、finished。
SKU Number 文字填写 否 若申请单关联的任一 SKU 编号命中输入内容，则该申请单会被展示。

列表字段

字段名称 数据来源 交互方式 是否必填 备注
Number of Allocation Request 申请单本地模拟数据 只读展示 是 编号规则为 DB + YYYYMMDD + ####。
From Warehouse 申请单本地模拟数据 只读展示 是 展示申请单的来源仓。
To Warehouse 申请单本地模拟数据 只读展示 是 展示申请单的目标仓。
Total of Allocation Quantity SKU 明细数量汇总 只读展示 是 展示该申请单下所有 SKU 明细数量的汇总值。
Submitter 申请单本地模拟数据 只读展示 是 展示提交人。
Creation Date 申请单本地模拟数据 只读展示 是 展示申请创建日期。
Request Order Status 状态枚举 只读展示 是 使用状态标签便于扫描。
Action 当前列表行 链接按钮 是 点击 Details 打开详情弹窗；操作列固定在表格右侧。

详情弹窗字段

字段名称 数据来源 交互方式 是否必填 备注
Request Order Number 当前申请单 只读展示 是 用于和列表中的申请记录保持一致。
Submitter 当前申请单 只读展示 是 展示提交该调拨申请的人员。
From Warehouse 当前申请单 只读展示 是 展示库存调出的仓库。
To Warehouse 当前申请单 只读展示 是 展示库存调入的仓库。
Creation Date 当前申请单 只读展示 是 展示申请创建日期。
Execution Date 当前申请单 只读展示 否 展示计划执行日期。
Total Allocation Quantity SKU 明细数量汇总 只读展示 是 展示当前申请下所有 SKU 明细数量的合计值。
Request Order Status 状态枚举 只读展示 是 展示当前申请状态。
SKU Lines 当前申请单 SKU 明细 表格展示 是 包含 SKU Number、SKU Name、Batch Number、Quantity。
Remark 当前申请单 只读展示 否 展示申请提交时填写的备注信息；没有备注时显示为空值占位。
